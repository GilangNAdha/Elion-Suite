## Original pixel art and material illustrations

The 48 knight sprite frames and Snow Court scene are original procedural pixel art generated by `scripts/make-pixel-art.py`. The supplied reference images informed the silhouettes, pixel aesthetic and setting; the reference photographs/art files are not bundled as sprites. The physical turntable is an original CSS/SVG illustration. The application shell's color and shape data comes from Elion's token set.

## MiniCPM Desk Pet API and Nova artwork

https://github.com/OpenBMB/MiniCPM-Desk-Pet provides the documented local API used
by Elion's independent connector. Its AGPL application/runtime code and its
separately restricted character artwork are **not** embedded or copied into Elion.
The user installs and runs the official local model service separately, under its
own notices and model-weight licence. Elion does not download its model weights.

Nova is **original Elion artwork**, generated by `scripts/make-nova.py`: 56
transparent pixel frames. The earlier original knight sprites remain only for
legacy/optional content. No MiniCPM, Clawd, Calico or Cloudling sprite assets are
included. See `docs/STUDIO-INTEGRATION.md` for the integration and privacy boundary.
