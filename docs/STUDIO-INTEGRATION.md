# Elion Studio — BlockSuite, Nova and motion

Implemented from the user's revised direction on 8 September 2026.

> **Latest clarification:** Nova is now a global floating overlay controlled by Settings, with no separate pet page or navigation tab. See [Floating pet](FLOATING-PET.md) for the current interaction model and preview.

## Decisions confirmed with the user

1. **MiniCPM AI + original Elion pet.** Connect to the real local API, without copying MiniCPM Desk Pet's AGPL app code or restricted artwork.
2. **Actual AFFiNE / BlockSuite engine.** Not a CSS imitation of an editor. Preserve existing Elion data and keep an advanced-editor compatibility route.
3. **A lighter, more animated interface.** The new motion/glow request supersedes the earlier ban on dock hover animation and decorative glow. The palette, readable typography, quiet focus environment and reduced-motion requirements remain.

## What changed

### Workspace: actual BlockSuite

`@blocksuite/presets`, `@blocksuite/blocks`, `@blocksuite/store` and related packages are pinned to the coherent **0.19.5 standalone release**. Its public `DocCollection` / `AffineEditorContainer` API is used; no test-only workspace implementation is shipped.

- Workspace opens to a document library with search, favourites and real document/canvas creation.
- Opening a document mounts the real editor, with rich text, native slash commands and contextual formatting.
- Doc and Canvas modes share the same Yjs document. Shape drawing, notes, pen, pan and selection are driven by BlockSuite's public controllers.
- Compact canvas tools are the default. **Show all native canvas tools** exposes the original broader BlockSuite palette when needed.
- The native document title and body align to one left edge. A narrow application rail replaces the old doubled full-width sidebars.
- Theme variables apply to the native editor and its controls; document prose remains bounded in width.
- Native undo/redo, version snapshots, image/blob persistence and voice insertion are integrated.

### Data and migration

The existing Dexie `pages` table remains the document aggregate:

- `PageRecord.native.update`: base64 Yjs state, including rich formatting and canvas geometry.
- `PageRecord.blocks`: compatibility/search projection, not a second independent document database.
- The shared `blobs` table stores native media under a `blocksuite:` prefix.
- Before first conversion, **Before BlockSuite migration** saves the original Elion blocks. New snapshots also include native state. Restoring a version first saves the current version for recovery.
- Plain text, headings, lists, checklists, code and dividers migrate to native blocks.
- Existing Elion databases mount as custom native blocks with **React portals into the existing `DatabaseBlock`**. They still use the same item store; rows are not cloned into a second task system.
- Unsupported Elion layouts, galleries, drawings and duel blocks retain their original payload and descendants in an explicit preserved block. **Open advanced Elion editor** is available at `/workspace/:pageId/legacy-edit`.
- Basic legacy text/checklist/heading edits are merged back by stable block ID. Rich native-only structures should be edited in BlockSuite rather than treated as fully interchangeable with the old canvas.
- Route changes flush pending saves. A bounded local write-ahead record protects small/medium documents against immediate page reloads; IndexedDB remains canonical. Very large documents can exceed the write-ahead quota, so wait for **All changes saved** before closing them.

This is a staged editor integration, not the entire AFFiNE product: cloud collaboration, AFFiNE accounts, server AI features and complete bidirectional conversion of every old/new block type are not included.

### Nova: original animated companion

The old Snow Court presentation is no longer the default pet. Nova is original pixel art generated by `scripts/make-nova.py`, with **56 transparent frames**: idle, cheer, thinking, talking, typing, sleeping and waving.

- The shared pet mood drives idle/focus/completion behavior.
- The MiniCPM reply state drives thinking and talking poses.
- A movable, keyboard-positionable companion can be pinned beside documents and tasks.
- The chat panel can open from the floating pet; it supports streaming replies, stop, clear and explicit work-context opt-in.
- Conversations stay in memory for the current session. They are not saved in companion preferences.
- No screen capture, file scanning, global agent-hook installation or autonomous app actions were added.
- The legacy duel remains available in preserved document content. Pet widgets in old Lockdown presets are retained as data, but the visible pet is now the global overlay.

### MiniCPM connection

The integration follows MiniCPM Desk Pet's real gateway protocol:

- `GET /api/health` and `/api/models`
- `POST /api/warmup`
- `POST /api/chat`, decoding `data: {"event":"start|delta|think|end|error", ...}` SSE frames

The browser calls **relative** `/api/companion/*` URLs. Vite development and preview middleware forward only approved operations to a loopback target. Electron uses its preload/main-process bridge. Browser-facing code never calls `localhost` to reach the user's computer.

Default upstream: `http://127.0.0.1:18765`. To use another local gateway, set `ELION_MINICPM_TARGET` in the environment of the Elion server or Electron process. It is intentionally **not** a `VITE_` variable and is not sent to browser code. Non-loopback URLs, credentials in target URLs, and unapproved gateway operations are rejected.

#### To use real chat

1. Install and run [MiniCPM Desk Pet](https://github.com/OpenBMB/MiniCPM-Desk-Pet).
2. Finish its model download/setup and leave its local gateway running.
3. Run Elion on that same computer (web server or desktop app).
4. Enable **Settings > Floating pet**, open **Open pet chat**, then select **Connect MiniCPM**.

An Arena-hosted browser preview targets its **sandbox server**, not the user's PC. It cannot discover the user's local model through their browser. No MiniCPM model weights were downloaded or model runtime launched in this sandbox. When disconnected, chat cannot send a fabricated reply.

### React Bits motion

Application-specific adaptations of **SpotlightCard**, **StarBorder** and **Dock** were added with the upstream MIT + Commons Clause notice retained. The dock magnifies with transforms rather than resizing its layout; native links and keyboard focus are kept. Glow is reserved for a small number of interactive focal points. Nova has its own frame clock.

All of these respect both the app's reduced-motion setting and the OS preference. Motion uses the installed `motion` React runtime. Third-party notices are available in Settings and at `/legal/notices.txt` in development/production builds.

## Validation and boundaries

Automated checks cover real native rich-text formatting, immediate reload, actual canvas geometry and mode persistence, embedded Elion item editing, native and legacy dictation undo, document renaming, native version restore, shared blob/media persistence, Nova motion/drag/pinning, disconnected chat behavior, SSE protocol handling, opt-in context and loopback proxy restrictions.

MiniCPM tests use an explicitly labelled **protocol fixture**, not real neural inference. Model quality and a real Windows MiniCPM installation remain manual verification tasks. The older native GPU/Parakeet speech-dictation gap is unchanged by this companion integration.

The dependency audit remains at the pre-existing **27 advisories** (6 moderate, 18 high, 3 critical) after overriding the newly introduced file parser to 21.3.2. No blanket breaking dependency upgrade or production-security certification is claimed. BlockSuite is a substantial lazy-loaded editor; its added bundle size is a deliberate trade-off versus the old custom editor.
